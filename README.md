## 📈 Code Quality Rules I Live By
* **🧵 Thread Safety First:** Keeping heavy math, external API requests, and database storage off the main server thread to protect the 20.0 TPS.
* **🧹 Zero Memory Leaks:** Properly cleaning up collection maps and custom listeners on server reload to keep heap usage low.
* **🏗️ Clean Code Design:** Writing well-documented, object-oriented Java utilizing clean patterns like Factories and Observers.
