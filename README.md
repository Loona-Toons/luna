## 📈 Code Quality & Best Practices
When developing custom backend systems, I strictly adhere to performance-first practices:
* **Thread Safety:** Keeping heavy math, external API requests, and database storage off the main server thread to protect the tick rate.
* **Memory Management:** Avoiding static memory leaks by properly cleaning up collection maps and custom listeners on server reload.
* **Clean Code:** Writing well-documented, object-oriented Java with proper encapsulation and design patterns (like Singletons, Factories, and Observers).
